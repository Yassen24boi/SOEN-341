# Sprint 2 Summary Report
**Project:** CareerConnect – Job Search and Application Tracking Platform  
**Course:** SOEN 341 – Software Process

### 1. Sprint Objectives
Sprint 2 focused on expanding CareerConnect from basic user authentication and CV uploading into a more complete job-search and application management platform. The main objectives included implementing professional profiles, multiple CV management, job browsing and filtering, application tracking, recruiter job posting management, and automated testing.

### 2. Features and Functionality Implemented
The team implemented professional profile creation, editing, and viewing (US-04 to US-06), alongside multiple CV management with customizable labels and default CV selection (US-07). Job seekers can browse and filter job listings, view job details, and apply to positions (US-08 to US-12). Application confirmation, status tracking, and withdrawal functionality were also assigned for development (US-13 to US-15).

On the recruiter side, the team developed job posting management functionality (US-16 to US-19), including creating, editing, opening/closing, and deleting job postings. Additionally, the team established an automated testing pipeline using GitHub Actions and developed API, UI, and acceptance tests for implemented features.

### 3. Team Innovation and Original Features
A key original feature is the **multi-CV management system**, allowing job seekers to maintain several resumes, label them, and select a default CV for applications. The recruiter dashboard also provides centralized job posting management, allowing recruiters to update listings and control their availability.

### 4. Challenges and Resolutions
The team encountered challenges integrating frontend, backend, and database functionality while developing multiple features simultaneously. These challenges were addressed through smaller development tasks, GitHub pull requests, peer code reviews, and coordination using the shared `develop` branch. Automated testing was also introduced to improve consistency and detect issues during integration.
