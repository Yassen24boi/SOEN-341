# Sprint 2 Work Plan — CareerConnect

## Sprint Overview

Sprint 2 focuses on expanding CareerConnect's functionality by implementing
core job-seeking features, integrating frontend and backend components,
and improving collaboration through Agile development practices.

Building on Sprint 1, technical responsibilities will be distributed
among team members to ensure individual contributions to development,
testing, and project management.

---

## Sprint Goal

Complete user profile and resume management, implement job searching
and application tracking, begin recruiter dashboard development,
and establish continuous integration and acceptance testing.

## Acceptance Testing

At least two acceptance tests must be created for every user story
from Sprint 1 and Sprint 2.

### Testing Responsibilities

**Julia Kyrychuk — Testing Coordinator**
- Coordinate acceptance testing activities.
- Assist in preparing test cases.
- Execute tests against implemented features.
- Document test results and identified bugs.
- Verify that corrected features meet acceptance criteria.

**Noor Rabie — GitHub Issue Management**
- Create acceptance test Issues.
- Apply appropriate labels.
- Link acceptance tests to their corresponding user stories.
- Organize testing tasks on the GitHub Project Board.

**All Developers**
- Define acceptance criteria for assigned features.
- Assist with testing their implemented functionality.
- Resolve identified bugs.
- Provide evidence of completed tests.

## Definition of Done

A task is considered complete when:

- Required functionality has been implemented.
- Relevant tests have passed.
- Code has been reviewed and approved.
- Changes have been merged into the appropriate branch.
- Required CI checks pass.
- GitHub Issue status has been updated.
- Individual contribution logs have been updated.
- AI usage has been documented where applicable.
