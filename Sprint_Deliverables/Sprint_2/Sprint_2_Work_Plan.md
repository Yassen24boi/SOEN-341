# Sprint 2 Work Plan — CareerConnect
## 1. Sprint Overview

Sprint 2 focuses on expanding CareerConnect's core functionality,
integrating frontend and backend components, and improving collaboration
through Agile development practices.

Building on Sprint 1, development responsibilities will be distributed
among team members to ensure individual technical contributions.

The team will prioritize the completion of three core features while
beginning development of the recruiter dashboard, which will continue
into Sprint 3.

---

## 2. Sprint Goal

The primary goal of Sprint 2 is to deliver a functional job search
and application management system.

The team aims to:

- Complete user profile and resume management.
- Implement job search and filtering functionality.
- Implement job application submission and tracking.
- Begin recruiter dashboard and posting management development.
- Establish a Continuous Integration (CI) pipeline.
- Create acceptance tests for Sprint 1 and Sprint 2 user stories.
- Maintain organized GitHub Issues, tasks, and project documentation.
- Ensure all team members contribute to development and testing.
